## ClickZetta SQL 语法规则（生成 SQL 前必须对照自检）

### DDL 关键规则

```sql
-- ❌ 普通表不支持 OR REPLACE
CREATE OR REPLACE TABLE t (...)
-- ✅ 正确
CREATE TABLE IF NOT EXISTS t (...)

-- ✅ Dynamic Table / View / MV 支持 OR REPLACE
CREATE OR REPLACE DYNAMIC TABLE dt REFRESH INTERVAL 1 MINUTE VCLUSTER vc AS SELECT ...

-- ❌ DROP INDEX 不带 ON table
DROP INDEX idx ON table_name
-- ✅ 正确
DROP INDEX idx

-- 索引：BLOOMFILTER 无 USING 关键字
CREATE INDEX idx ON t (col) BLOOMFILTER  -- ✅
```

### DML 类型转换（最高频错误）

```sql
-- ❌ 字符串不能直接写入日期/时间/BOOLEAN/JSON 列
INSERT INTO t VALUES ('2024-01-15', 'true', '{"k":1}')

-- ✅ 必须显式转换
INSERT INTO t VALUES (
  DATE '2024-01-15',           -- 或 CAST('2024-01-15' AS DATE)
  TRUE,                         -- 或 CAST(1 AS BOOLEAN)
  PARSE_JSON('{"k":1}')        -- 或 CAST('{"k":1}' AS JSON)
)

-- ⚠️ WHERE 中字符串可隐式比较，但 INSERT/UPDATE SET 中不行
WHERE dt = '2024-01-01'              -- ✅ WHERE 可以
UPDATE t SET dt = '2024-01-01'       -- ❌ 需 CAST
```

### 不支持的语法（禁止生成）

```
❌ BEGIN / COMMIT / ROLLBACK（无事务）
❌ UNION / INTERSECT / EXCEPT（无集合运算，用 JOIN 替代）
❌ WITH RECURSIVE（无递归 CTE）
❌ CREATE TEMPORARY TABLE（用 CTE 替代）
❌ WHEN NOT MATCHED BY SOURCE THEN DELETE（MERGE 不支持，需两步操作）
❌ MERGE 中 DELETE 在 UPDATE 之前（UPDATE 必须先于 DELETE）
❌ CREATE OR REPLACE TABLE（普通表不支持）
```

### 常用函数替换

| 错误写法 | ClickZetta 正确写法 |
|---|---|
| `IFF(cond, a, b)` | `IF(cond, a, b)` |
| `LISTAGG(col, ',')` | `GROUP_CONCAT(col SEPARATOR ',')` |
| `CHARINDEX(sub, s)` | `INSTR(s, sub)` ← 参数顺序相反！ |
| `ZEROIFNULL(x)` | `COALESCE(x, 0)` |
| `NULLIFZERO(x)` | `NULLIF(x, 0)` |
| `OBJECT_AGG(k, v)` | `MAP_AGG(k, v)` |
| `ARRAY_SIZE(arr)` | `SIZE(arr)` |
| `LATERAL FLATTEN(input=>arr)` | `LATERAL VIEW EXPLODE(arr)` |
| `data:key`（SF 半结构化） | `data['key']` |
| `VARIANT` 类型 | `JSON` 类型 |
| `NUMBER(p,s)` | `DECIMAL(p,s)` |
| `SELECT TOP 10` | `SELECT ... LIMIT 10` |

### Pipeline 语法

```sql
-- Dynamic Table
CREATE OR REPLACE DYNAMIC TABLE dt_name
  REFRESH INTERVAL 1 MINUTE
  VCLUSTER vc_name
AS SELECT ...;

-- Stream 元数据（替代 METADATA$ACTION）
__change_type   -- 'INSERT' / 'DELETE'
__change_seq    -- 变更序号

-- COPY INTO（替代 Snowflake @stage）
COPY INTO t FROM VOLUME v/path/ USING CSV
  FILE_FORMAT = (FIELD_DELIMITER = ',', SKIP_HEADER = 1);
```

### 数据类型速查

```
整数：TINYINT / SMALLINT / INT / BIGINT
浮点：FLOAT / DOUBLE / DECIMAL(p,s)
字符：STRING（推荐）/ VARCHAR(n) / CHAR(n)
时间：DATE / TIMESTAMP
布尔：BOOLEAN
复合：ARRAY<T> / MAP<K,V> / STRUCT<f:T> / JSON
```
