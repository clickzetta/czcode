## ClickZetta SQL 语法规则（生成 SQL 前必须逐条对照自检）

### 一、DDL 陷阱

```sql
-- ❌ 普通表不支持 OR REPLACE
CREATE OR REPLACE TABLE t (...)
-- ✅ 正确
CREATE TABLE IF NOT EXISTS t (...)

-- ✅ Dynamic Table / View / MV 支持 OR REPLACE
CREATE OR REPLACE DYNAMIC TABLE dt REFRESH INTERVAL 1 MINUTE VCLUSTER vc AS SELECT ...

-- ❌ 不支持临时表
CREATE TEMPORARY TABLE t (...)
-- ✅ 用 CTE 替代
WITH t AS (SELECT ...)

-- ❌ 不支持 SEQUENCE 对象
CREATE SEQUENCE seq START 1
-- ✅ 用 IDENTITY 列替代
CREATE TABLE t (id BIGINT IDENTITY(1), ...)

-- ❌ DROP INDEX 不带 ON table（Snowflake 语法）
DROP INDEX idx ON table_name
-- ✅ 正确（不需要 ON）
DROP INDEX idx

-- ❌ 索引语法错误（USING 关键字不对）
CREATE INDEX idx ON t (col) USING BLOOM_FILTER
-- ✅ 正确（关键字是 BLOOMFILTER，无 USING）
CREATE BLOOMFILTER INDEX idx ON TABLE t (col)

-- ❌ Dynamic Table 不支持 ALTER 修改参数
ALTER DYNAMIC TABLE t SET REFRESH INTERVAL 10 MINUTE
-- ✅ 用 CREATE OR REPLACE 重建
CREATE OR REPLACE DYNAMIC TABLE t REFRESH INTERVAL 10 MINUTE VCLUSTER vc AS SELECT ...

-- ❌ 分区语法错误（不能直接用列名）
PARTITIONED BY (year, month)
-- ✅ 用 transform 函数
PARTITIONED BY (years(created_at), months(created_at))
-- 支持：years() months() days() hours() bucket(N,col) truncate(col,W)

-- ❌ 同义词不指定对象类型
CREATE SYNONYM s FOR t
-- ✅ 必须指定类型
CREATE SYNONYM s FOR TABLE t
DROP SYNONYM s FOR TABLE
```

### 二、DML 类型转换

```sql
-- ❌ 字符串不能直接写入日期/时间/BOOLEAN/JSON 列
INSERT INTO t VALUES ('2024-01-15', 'true', '{"k":1}')
UPDATE t SET dt = '2024-01-15'

-- ✅ 必须显式转换
INSERT INTO t VALUES (
  DATE '2024-01-15',
  TIMESTAMP '2024-01-15 12:00:00',
  TRUE,
  PARSE_JSON('{"k":1}')
)
UPDATE t SET dt = CAST('2024-01-15' AS DATE)

-- ⚠️ WHERE 中字符串可隐式比较，但 INSERT/UPDATE SET 中不行
WHERE dt = '2024-01-01'              -- ✅ 允许
UPDATE t SET dt = '2024-01-01'       -- ❌ 需 CAST
```

### 三、MERGE 陷阱

```sql
-- ❌ DELETE 不能在 UPDATE 之前
MERGE INTO t USING s ON t.id = s.id
WHEN MATCHED THEN DELETE
WHEN MATCHED THEN UPDATE SET ...

-- ✅ UPDATE 必须在 DELETE 之前
MERGE INTO t USING s ON t.id = s.id
WHEN MATCHED AND s.is_deleted = 0 THEN UPDATE SET t.amount = s.amount
WHEN MATCHED AND s.is_deleted = 1 THEN DELETE
WHEN NOT MATCHED THEN INSERT (id, amount) VALUES (s.id, s.amount)

-- ❌ 不支持 WHEN NOT MATCHED BY SOURCE
WHEN NOT MATCHED BY SOURCE THEN DELETE
-- ✅ 两步操作替代
-- Step 1: MERGE（处理匹配行）
-- Step 2: DELETE FROM target WHERE id NOT IN (SELECT id FROM source)
```

### 四、不支持的语法（禁止生成）

```sql
-- ❌ 无事务支持
BEGIN; COMMIT; ROLLBACK; BEGIN TRANSACTION; START TRANSACTION;
-- ✅ 用 MERGE 实现原子 UPSERT

-- ❌ 无集合运算
UNION / UNION ALL / INTERSECT / EXCEPT
-- ✅ MINUS 支持（等同于 EXCEPT）
-- ✅ INTERSECT → INNER JOIN + DISTINCT
-- ✅ EXCEPT → LEFT JOIN + WHERE NULL

-- ❌ 无递归 CTE
WITH RECURSIVE ...

-- ❌ 不支持 OPTIMIZE ZORDER
OPTIMIZE t ZORDER BY (col)
-- ✅ 只支持小文件合并
OPTIMIZE t
```

### 五、权限管理语法

```sql
-- 授权
GRANT SELECT ON TABLE schema.table TO ROLE role_name;
GRANT INSERT, UPDATE ON TABLE schema.table TO ROLE role_name;
GRANT ALL ON SCHEMA schema TO ROLE role_name;
GRANT ALL ON DATABASE db TO ROLE role_name;
GRANT ROLE role_name TO USER user_name;

-- 撤权
REVOKE SELECT ON TABLE schema.table FROM ROLE role_name;
REVOKE ROLE role_name FROM USER user_name;

-- 查看权限
SHOW GRANTS ON TABLE schema.table;
SHOW GRANTS TO ROLE role_name;
SHOW GRANTS TO USER user_name;
SHOW ROLES;
SHOW USERS;
```

### 六、性能调优常用语句

```sql
-- 查看执行计划
EXPLAIN SELECT ...;
EXPLAIN ANALYZE SELECT ...;  -- 实际执行并返回统计

-- 小文件合并（不支持 ZORDER）
OPTIMIZE table_name;

-- 查看表统计信息
SHOW TABLE EXTENDED LIKE 'table_name';
SHOW TABLES IN schema_name;

-- 创建索引（BLOOMFILTER，无 USING 关键字）
CREATE BLOOMFILTER INDEX idx ON TABLE t (col);
DROP INDEX idx;  -- 不需要 ON table_name

-- 分析表（更新统计信息）
ANALYZE TABLE table_name;
```

### 七、VCluster 管理

```sql
-- 查看 VCluster
SHOW VCLUSTERS;
SHOW VCLUSTERS WHERE vcluster_type = 'ANALYTICS';
SHOW VCLUSTERS WHERE state = 'SUSPENDED';
DESC VCLUSTER vc_name;

-- 修改 VCluster 参数（正确参数名）
ALTER VCLUSTER IF EXISTS vc_name SET VCLUSTER_SIZE = 16;
ALTER VCLUSTER IF EXISTS vc_name SET AUTO_SUSPEND_IN_SECOND = 300;  -- ⚠️ 不是 AUTO_SUSPEND
ALTER VCLUSTER IF EXISTS vc_name SET AUTO_RESUME = TRUE;
-- 分析型专用
ALTER VCLUSTER IF EXISTS bi_vc SET MIN_REPLICAS = 1 MAX_REPLICAS = 5 MAX_CONCURRENCY = 16;

-- 暂停/恢复（必须用 ALTER VCLUSTER，不是 SUSPEND/RESUME VCLUSTER）
ALTER VCLUSTER IF EXISTS vc_name SUSPEND;        -- ✅ 等待当前作业完成
ALTER VCLUSTER IF EXISTS vc_name SUSPEND FORCE;  -- ✅ 立即中断所有作业
ALTER VCLUSTER IF EXISTS vc_name RESUME;         -- ✅ 启动集群

-- ❌ 错误写法（不存在这种语法）
SUSPEND VCLUSTER vc_name;
RESUME VCLUSTER vc_name;

-- 切换当前会话集群
USE VCLUSTER vc_name;

-- 查看当前 VCluster
SELECT CURRENT_VCLUSTER();  -- 替代 CURRENT_WAREHOUSE()
```

### 八、作业管理（高频错误：KILL vs CANCEL）

```sql
-- ✅ 查看作业（最近7天，最多10000条）
SHOW JOBS;
SHOW JOBS IN VCLUSTER vc_name;
SHOW JOBS WHERE execution_time > INTERVAL 2 MINUTE;
SHOW JOBS WHERE status = 'FAILED';
SHOW JOBS LIMIT 100;

-- ✅ 取消某集群的所有作业
ALTER VCLUSTER IF EXISTS vc_name CANCEL ALL JOBS;

-- ✅ 查看作业历史（information_schema）
SELECT job_id, virtual_cluster, execution_time, status, start_time
FROM sys.information_schema.job_history
WHERE status = 'FAILED'
ORDER BY start_time DESC
LIMIT 50;

-- ❌ 不存在 KILL JOB 命令（MySQL 惯例，ClickZetta 不支持）
KILL JOB job_id;
KILL QUERY job_id;

-- ❌ 不存在 CANCEL JOB <job_id> 单独取消某个作业的语法
CANCEL JOB job_id;

-- ⚠️ 如需取消单个作业，只能通过取消整个集群的所有作业实现：
ALTER VCLUSTER IF EXISTS vc_name CANCEL ALL JOBS;
-- 或强制停止集群（会中断所有作业）：
ALTER VCLUSTER IF EXISTS vc_name SUSPEND FORCE;
```

### 十、Volume 管理

```sql
-- 查看 Volume
SHOW VOLUMES;
DESCRIBE VOLUME vol_name;

-- COPY INTO（使用 VOLUME，不是 @stage）
COPY INTO t FROM VOLUME v/path/ USING CSV
  FILE_FORMAT = (FIELD_DELIMITER = ',', SKIP_HEADER = 1);

-- ❌ Snowflake @stage 语法
COPY INTO t FROM @stage/path/file.csv

-- ❌ PATTERN 关键字
COPY INTO t FROM VOLUME v PATTERN = '.*\.csv'
-- ✅ 用 REGEXP
COPY INTO t FROM VOLUME v REGEXP '.*\.csv' USING CSV
```

### 十一、函数替换速查

| 错误写法 | ClickZetta 正确写法 | 注意 |
|---|---|---|
| `CURRENT_DATABASE()` | `CURRENT_WORKSPACE()` | |
| `CURRENT_WAREHOUSE()` | `CURRENT_VCLUSTER()` | |
| `IFF(cond, a, b)` | `IF(cond, a, b)` | |
| `CHARINDEX(sub, s)` | `INSTR(s, sub)` | ⚠️ 参数顺序相反！ |
| `TRY_TO_DATE(s)` | `TRY_CAST(s AS DATE)` | |
| `DATE_PART('year', dt)` | `EXTRACT(YEAR FROM dt)` 或 `YEAR(dt)` | |
| `// comment`（SF 注释） | `-- comment` | |
| `NUMBER(p,s)` | `DECIMAL(p,s)` | |
| `VARIANT` 类型 | `JSON` 类型 | |

### 十二、数据类型速查

```
整数：TINYINT / SMALLINT / INT / BIGINT
浮点：FLOAT / DOUBLE / DECIMAL(p,s)   -- 无 NUMBER 类型
字符：STRING（推荐，无长度限制）/ VARCHAR(n) / CHAR(n)
时间：DATE / TIMESTAMP / TIMESTAMP_NTZ
布尔：BOOLEAN
复合：ARRAY<T> / MAP<K,V> / STRUCT<f:T> / JSON  -- 无 VARIANT 类型
```
